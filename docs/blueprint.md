# **App Name**: BGC Atlas

## Core Features:

- Data Exploration: Browse BGCs, GCFs, Samples, and Taxonomy with filtering and sorting.
- Entity Detail Pages: Display detailed information about BGCs, GCFs, Samples, and Taxa.
- Advanced Search: Implement a search functionality for metadata and sequence-based queries, with tabbed sub-views for results.
- Statistics Dashboard: Visualize database statistics using KPI tiles, charts (bar, doughnut, line), and a world map heat-map.
- Data Downloads: Enable users to download data dumps in various formats.
- Documentation and About Pages: Display documentation and project information using a markdown-based system.

## Style Guidelines:

- Primary color: Deep blue (#2358B8) for a scientific and professional feel.
- Accent color: Teal (#00B39F) for highlighting key elements and interactive components.
- Background color: Light gray (#F5F5F5) for light theme, dark gray (#333333) for dark theme, providing a neutral backdrop for data presentation. Both at approximately 20% saturation relative to the primary hue.
- Body text: 'Inter' sans-serif for clean and modern readability.
- Headline: 'Space Grotesk' sans-serif for impactful headings and titles. Paired with 'Inter' for body text.
- Use clear, consistent icons to represent data types and actions.
- Implement a 12-column responsive grid layout with a max-width of 1440px on desktop and full-width on mobile.
- Use subtle animations for loading states and transitions to improve user experience.
